# Roadmap

Loose, ordered blueprint of upcoming work. **Not a commitment** — items will be reordered, dropped, or split as the project evolves.

The difference between roadmap and milestone:

- **Roadmap** (this file): forward-looking sketch. Many items, no formal scope, no plan, no `spec.md`.
- **Milestone** (`docs/work/milestones/<slug>/`): one formal milestone at a time, with `spec.md` + `plan.md`. Created when you're ready to design that specific feature.

The hard rule *"one formal milestone at a time"* applies to milestones — not the roadmap.
