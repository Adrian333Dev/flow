Everything that has to be true before Flow installs on this machine and the beta starts. **Runs in the order written.** How an item is written: `docs/dev/layout.md`, the `backlog/` entry.

- [ ] **An MCP server set up for the whole machine is switched on only in the projects that use it.** Ruled by the user 2026-10-04, and held 2026-10-05 against a recommendation to leave MCP servers alone: a server one project uses has no place in every other project's context. One the user wants on everywhere stays on everywhere. Plugins and outside skills got the same treatment on 2026-10-05: machine setup switches off a plugin only some projects use, with `claude plugin disable <id> --scope user`, and takes over such a skill without `flow skills on`. The project's setup session then switches each on where the project's code uses it: `scripts/sessions/machine.md`, `project.md` and both forms.
  - **The approved mechanism.** Machine setup removes the server with `claude mcp remove <name> -s user` and saves its settings in `~/.flow/mcp-servers.json`, on the ignore list in `scripts/lib/machine/flow-repo.js` since it can hold API keys. The project's setup adds it back with `claude mcp add-json <name> '<json>' -s local`.
  - **Waiting on the user: how a restore undoes it.** Both commands rewrite `~/.claude.json`, Claude Code's own state file, and a migration copies every path it touches into the place's original. A project's original would then hold a machine file, and `flow restore project` would put the whole file back, undoing every server added since in every project. Recommended: no original records `~/.claude.json`. `flow restore machine` adds back each server in `~/.flow/mcp-servers.json`, and `flow restore project` removes the ones its setup added.
  - **Also waiting on the user: a project set up from the template switches nothing on.** `flow init` opens no session in an empty folder, nor where the user answers no to reading the files. Recommended: `flow init` then prints each plugin and skill off on this machine, with the command switching it on.
