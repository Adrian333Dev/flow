# Schliff

Read 2026-10-04 from `repos/tools/schliff/`. 16 stars, MIT. Scores an instruction file from 0 to 100 on fixed rules, with no model: structure, coverage, efficiency, composability and clarity. The same file gets the same score on every machine. A guard layer stops padding and keyword stuffing from raising it.

## What Flow could take

Nothing. Flow's writing rules in `references/style.md` are specific to Flow, and a general score would grade against someone else's taste. Its one idea worth keeping is already Flow's: a rule check is a function, with no model in it, per `skills/tools/file-findings/references/write-checks.md`.
