# Plannotator

Read 2026-10-04 from `repos/tools/plannotator/`. About 9,100 stars, Apache 2.0. A browser page for marking up an agent's plan, a document, a diff or a pull request. The comments go back to the agent as feedback.

## Against Flow

Flow denies `ExitPlanMode`, the event Plannotator started on. Flow's plans and specs are files the user reads in the editor, and feedback goes through the conversation.

## What Flow could take

Nothing now. Marking up a spec line by line belongs with the ticket board in `lab/backlog/beta.md` → the mods item, if the user ever wants it.
